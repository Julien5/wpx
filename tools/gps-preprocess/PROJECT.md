## Tool

I need a tool to estimate the power generated by a cyclist from the data recorded by its GPS. 
The input data are available in a csv file:
```
main > head input.csv 
No,Latitude,Longitude,Altitude,Temperature,Speed,Heartrate,Cadence,Power,Date,Time
1,47.992121,7.874056,296.8,23.000,0.00,79,,,2026/06/06,07:11:08
2,47.992109,7.874046,296.8,23.000,0.00,79,,,2026/06/06,07:11:09
3,47.992106,7.874039,296.8,22.000,0.00,79,,,2026/06/06,07:11:10
4,47.992100,7.874031,296.8,22.000,0.00,80,,,2026/06/06,07:11:11
5,47.992105,7.874020,296.8,22.000,0.00,85,,,2026/06/06,07:11:12
6,47.992108,7.874021,296.8,22.000,0.00,87,,,2026/06/06,07:11:13
```

I have an algorithm that computes the power for a given slope and speed.
Because the data, we have to process the input data before passing them to that algorithm.
0 - read input
1 - oversample to a 1-Hz sampling rate
2 - filter outliers:
    * if speed>max_speed (e.g. 90 km/h) => remove 
    * if vertical speed > 3m/s => remove 
	* then the removed points are replace by there linear interpolation with the non-removed neighbors.
3 - smooth the speed: moving average with a window of 3-5 seconds 
4 - compute the slope using the linear regression of the neighbors

Then, the smoothed speed and the slope data can be passes to the power formula.

**The implementation should be in rust.**

Now let me detail each step.

## Read Input 

input: filename.csv (passed on the command line)
output: `Vec<Input>`
where
```
struct Input {
	time:f64, // seconds
	distance:f64 // meters
	elevation:f64 // meters
	speed: f64 // meters per second
	vertical_speed: f64 // meters per second,
}
```
- discard points where the time delta to the previous one is zero (speed cannot be computed)
- the distance is computed accumulating the Haversine distance between the lat,long points 

`fn read_csv(filename:&str) -> Vec<Input>`.

## Oversample

input: `input::Vec<Input>` 
output: `oversample: Vec<Input>`
we need one point per second.

first pass: create the oversampled vector with Nan for the times where there is no input
second pass: replace Nan using the non-Nan neighbors and linear interpolation 

`fn oversample(input:&Vec<Input>) -> Vec<Input>`.

## Filter outliers 

input: `oversample::Vec<Input>` 
output: `clean: Vec<Input>`

first pass:
replace all fields (except time) with Nan if 
- if speed > max_speed (input argument --max-speed) 
- if elevation_speed > max_elevation_speed (input argument --max-evelation-speed) 
second pass:
- replace Nan using the non-Nan neighbors and linear interpolation 

`fn filter_outliers(input:&Vec<Input>) -> Vec<Input>`.

## Smooth speed and compute slope 

input: `oversample::Vec<Input>` 
output: `clean: Vec<Smooth>`

where the first members of Smooth are a copy of the Input members, but two are added:
```
struct Smooth {
	time:f64, // seconds
	elevation:f64, // meters
	speed: f64, // meters per second
	smooth_speed: f64, // meters per second
	vertical_speed: f64, // meters per second,
	slope: f64
}
```
- smooth_speed averages the speed with a moving average on a certain window (--speed-smooth-window, in seconds).
- for each input, the slope is the result of the linear regression of the (distance,elevation) curve on a
certain window (--slope-reg-window, in seconds).

`fn smooth_speed(input:&Vec<Input>) -> Vec<f64>`.
`fn slope(input:&Vec<Input>) -> Vec<f64>`.

## Parameters

--max-speed: kmh, defaults = 60
--max-evelation-speed: mps: default=3
--speed-smooth-window: seconds, default:10
--slope-reg-window: seconds, default:50

## Output

To check the result at each step, we need one csv file for use with gnuplot.
Generate it at the end:
processing.csv

| time | distance | elevation | speed | smooth_speed | slope | 

- time: the number of hours (easier to read on a long time span), save at least 4 digits precision.
- distance: in km
- speed: in km/h
- elevation: in meters
- smooth_speed: in km/h
- slope: in %

I need several gnuplot script to plot the data.
All plots have the time on the x-axis.
