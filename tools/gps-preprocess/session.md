| `output.rs` | `write_csv(smooth, raw, oversampled)` + `write_gnuplot(...)` | Write `processing.csv`; write 5 gnuplot scripts to `gnuplot/` |
| `main.rs` | `main()` | Parse args, run pipeline, call output |

### Edge cases / notes
- **Haversine** implemented as a standalone `fn` in `data.rs` or a utility
- **Linear interpolation** (`interpolate_nans`): finds NaN runs, replaces via lerp between bounding non-NaN values. Edge: all-NaN vector → leave as NaN; leading/trailing NaN → leave as NaN
- **Window boundary**: at edges where window extends past data, clamp to available range (e.g., window of 10 at index 0 uses indices 0..5)
- **Zero distance in slope regression**: if all points in window have same distance, slope is 0 (no elevation change per distance)
